# Безопасность

## Где лежат секреты

Ни один секрет не хранится в коде и не попадает в git — все файлы ниже уже в `.gitignore`.

| Файл | Что внутри |
|---|---|
| `config.json` | токен Telegram-бота, chat_id, хеш пароля панели, секрет подписи сессий, URL heartbeat |
| `nvr.json` | логины и пароли регистраторов Dahua |
| `unifi.json` | доступ к контроллеру UniFi |
| `monitor.db` | история проверок и инцидентов |

Все они лежат рядом с exe (или `monitor.py`). Делая бэкап или пересылая папку, помни, что в ней секреты.

## Как устроена защита

- **Панель:** пароль — PBKDF2-хеш (200 000 раундов), сессия — подписанная cookie `HttpOnly` +
  `SameSite=Lax`. 5 неверных попыток с одного IP — блок на 15 минут. Смена пароля
  разлогинивает все устройства.
- **Telegram-бот** отвечает только владельцу — сохранённому `chat_id`. Кнопки тоже.
- **Регистраторы** — только чтение, одна попытка входа на запрос, пароли до браузера не доходят.
- **Запросы с чужих сайтов** отклоняются: страница из интернета, открытая на ПК в сети,
  не может дёрнуть API монитора, даже если пароль на панель выключен.
- **Обновление** берёт только exe, владелец которого — администратор ПК, и только после
  пробного запуска; неудачная версия откатывается автоматически.
- **Тревоги не глушатся извне:** названия Wi-Fi-сетей и устройств экранируются, а сообщение,
  которое Telegram не смог разобрать, уходит повторно простым текстом.

## Рекомендации по развёртыванию

- Не открывай порт 8081 в интернет. Снаружи — только через VPN или туннель с TLS.
- Включи пароль на панель, если к ней есть доступ не только с самого ПК.
- Для регистраторов заведи отдельного пользователя только с просмотром.

## Нашли уязвимость?

Не публикуйте её в открытом issue. Откройте приватный отчёт через
**Security → Report a vulnerability** на странице репозитория на GitHub.
